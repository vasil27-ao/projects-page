# Проекты

Небольшая адаптивная страница со списком проектов, поиском, созданием, редактированием и удалением. Проекты сохраняются в `localStorage` браузера и остаются на месте после обновления страницы. Данные локальны для текущего браузера; backend и база данных не используются.

## Запуск локально

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Vite выведет адрес локального сервера в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовая сборка появится в `dist`.

## Публикация на Vercel

Импортируйте репозиторий в Vercel. Платформа автоматически определит Vite; build command — `npm run build`, output directory — `dist`. Дополнительные переменные окружения не нужны.
