# Проверка

Проверка выполнена в локально запущенном приложении и production-сборке.

## Что проверено

- открытие формы по кнопке «Создать проект»;
- сообщение «Введите название проекта» при попытке сохранить форму без названия;
- закрытие формы кнопкой «Отмена» и клавишей Escape без сохранения;
- создание проекта с названием, описанием и выбранным статусом;
- появление нового проекта в списке сразу после сохранения, без перезагрузки;
- сохранение созданного проекта после обновления страницы;
- открытие формы редактирования с текущими значениями проекта;
- изменение названия и статуса проекта;
- сохранение изменений после обновления страницы;
- открытие диалога подтверждения удаления с названием выбранного проекта;
- отмена удаления без изменения списка;
- поиск исходного проекта «Telegram-бот поддержки»;
- поиск только что созданного проекта;
- состояние «Проекты не найдены» для запроса без совпадений;
- отображение длинного названия и длинного описания с корректным переносом строк;
- desktop layout при ширине 1440 px: поиск и кнопка находятся в одной строке, карточки — в три колонки;
- mobile layout при размере 375 × 812 px: поиск и кнопка находятся друг под другом и не перекрываются;
- отсутствие горизонтального скролла и выхода карточек за границы экрана на мобильном размере;
- удобство мобильной формы: поля и кнопки занимают доступную ширину, элементы не перекрываются;
- корректное размещение кнопок «Изменить» и «Удалить» на мобильном размере;
- расположение счётчика проектов на одной линии с заголовком на desktop и mobile;
- последовательная нумерация карточек по порядку создания вместо цифр из технического ID;
- отсутствие ошибок и предупреждений в консоли браузера;
- production-сборка командой `npm run build`.

## Обнаруженные проблемы и исправления

При первой production-сборке TypeScript сообщил, что параметр `allowImportingTsExtensions` нельзя использовать без `noEmit` или `emitDeclarationOnly` в `tsconfig.node.json`.

В `tsconfig.node.json` добавлен параметр `"noEmit": true`. После исправления TypeScript-проверка и Vite-сборка завершились успешно.

При добавлении локального сохранения, редактирования и удаления новых ошибок в ходе проверки обнаружено не было.
