# Проверка

После реализации страницы провела функциональную проверку и отдельно проверила адаптивность интерфейса.

## Что проверено

- открытие формы по кнопке «Создать проект»;
- валидация обязательного поля названия;
- создание нового проекта;
- появление созданного проекта в списке без перезагрузки страницы;
- поиск проектов по названию;
- отображение нескольких проектов при совпадении поискового запроса;
- состояние «Проекты не найдены» при отсутствии совпадений;
- отображение длинных названий и описаний без нарушения вёрстки;
- корректная работа дополнительных действий с проектами;
- отсутствие ошибок и предупреждений в консоли браузера;
- успешная production-сборка.

## Мобильная версия

Дополнительно проверила страницу на реальном мобильном устройстве:

- поле поиска и кнопка «Создать проект» не перекрываются;
- элементы не выходят за границы экрана;
- горизонтальный скролл отсутствует;
- форма и элементы управления остаются доступными и читаемыми.

## Обнаруженная и исправленная проблема

При первой production-сборке TypeScript сообщил, что параметр `allowImportingTsExtensions` нельзя использовать без `noEmit` или `emitDeclarationOnly` в `tsconfig.node.json`.

В `tsconfig.node.json` был добавлен параметр `"noEmit": true`.

После исправления TypeScript-проверка и production-сборка завершились успешно.
